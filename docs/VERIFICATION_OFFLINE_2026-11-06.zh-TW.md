# 網站來源停服與群組版面驗證（2026-11-06）

## 來源停服後仍可本機使用

以本機 production preview 驗收，停止本輪自行啟動的預覽服務，確認對應 port 的監聽數為 0；沒有停止原網站的正式服務。測試使用合成旅程。

1. 停服後重整每日行程，仍顯示完整原版介面、三個群組及既有安排。實際頁面有 2 個 stylesheet，字型與顏色正確，沒有退回裸 HTML。
2. 在停服狀態新增「離線保存驗收」安排及備註，保存成功。
3. 再次重整，安排名稱與備註均讀回，樣式仍存在。
4. 恢復預覽服務，再次重整，資料保留；未將本機合成資料送至 Firebase。

本輪關閉的是先前內建瀏覽器「來源停服重整後只剩裸 HTML」的候選產物回歸項目，**不是**宣稱已測過實體裝置飛航模式或正式 Pages 的所有快取情境。測試中其他網路服務仍可連線；雲端登入與 Google API 不列為離線功能。

## 長群組名稱

三個「驗收小隊」名稱加上「所有行程」原先擠在同一列，產生逐字直排。保留原版顏色、圖示與按鈕樣式，改為依可用寬度換行，不固定群組數量。

桌面實測四個按鈕各約 123 × 45px，以兩列呈現，名稱可橫向閱讀。修正只涉及群組控制的 flex 換行與文字配置；沒有更改分組、權限或保存行為。

正式 Pages 的根／子路徑、更新及快取回歸仍依 RELEASE_ACCEPTANCE 執行。真實雲端直接越權及首次自行部署的帳號持有人步驟亦未被本項取代。
