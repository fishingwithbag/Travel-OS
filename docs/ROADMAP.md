# Implementation roadmap

| Milestone | Deliverable | Exit condition |
|---|---|---|
| S0 | Clean repository and architecture decisions | No private source or credentials are tracked |
| S1 | Generic trip model and IndexedDB planner | Trips and itinerary items survive reloads |
| S2 | Firebase setup wizard and tenant rules | Authenticated membership controls all cloud access |
| S3 | Optional Google browser features | Core planner remains usable with no key |
| S4 | Backup, restore, accessibility and deployment checks | Clean restore and responsive browser checks pass |
| S5 | Public documentation, CI and beta | GitHub Pages deploys only after quality checks |

Milestones are committed separately so each published state remains reviewable and reversible.
