## 本批群組行為

- 更名保留 group ID 及所有關聯。
- 刪除前列出五類影響數量，選擇另一群組或所有人／共用，再次確認後一次保存旅程。
- 金額、分攤人數、預訂及行程內容維持原值，僅轉移關聯。
- 停車來源有資料且目標已有資料時拒絕操作，保留輸入及原旅程；不猜測該覆蓋哪份內容。
- 若轉為共用會與其他群組的停車設定混用，也要求先整理。移除最後群組後切回共用停車。
- 表單開啟後旅程版本有變更，拒絕舊表單保存，要求重新查看影響範圍。
