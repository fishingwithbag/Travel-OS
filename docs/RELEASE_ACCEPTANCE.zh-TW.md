## 新手設定必經流程

- [ ] 僅依 README 與 Step 1 完成自己網站的部署；官方 demo 不接收個人設定。
- [ ] 從無 Firebase 專案依 Step 2 建立 Spark、Web app、RTDB、Authentication、使用者及 Rules。
- [ ] Firebase config 與 database URL 可貼上／逐欄修改；service account 與私鑰被拒絕。
- [ ] Google 功能的專案、API、Key 限制、額度及驗證指引完整；Firebase 維持 Spark。
- [ ] 登入與本人範圍讀寫測試成功；錯誤可依畫面提示自行修正。
- [ ] 建立第一趟旅程，保存景點、備註、停車、航班，重新登入及換裝置讀回。
- [ ] 未設定 Google、API 拒絕、額度不足與離線都有可理解狀態；不顯示假成功。

涉及帳密、驗證碼、條款及計費決策時由帳號持有人操作，記錄此項操作，不將手動介入誤報成自動完成。
