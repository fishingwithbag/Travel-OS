# Travel OS

通用旅遊規劃網站的獨立開源工作目錄，目前為規劃階段，尚未實作或發布網站。

主要體驗：開啟網站 → 貼入自己的 Firebase Web config → 選填 Google Maps browser key → 驗證連線及登入 → 建立自己的旅程。

## 規劃功能

- 自訂目的地、日期、景點及每日行程。
- 航班、住宿、交通及費用管理。
- 網站內 Firebase 連線精靈與選用 Google Maps 功能。
- 本機儲存、資料匯出與還原。

目前僅建立專案骨架，以上功能尚未在此儲存庫實作，尚無可使用的網站或安裝包。
